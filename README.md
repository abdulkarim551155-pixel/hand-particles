# جزيئات اليد ✋✨

جزيئات تتحرك بحركة يدك قدام الكاميرا، باستخدام MediaPipe Hands و Three.js.

- **index.html**: نسخة الكاميرا، تشتغل بيد وحدة أو يدين:
  - ✋ كف مفتوح: تحرك الشكل
  - ✊ قبضة: تمسك الشكل وتلفّه
  - 👌 قرصة: الشكل التالي
  - ✌️ علامة النصر: الشكل السابق
  - 🙌 يدين: تبعدهم يكبر، تقربهم يصغر، تميّلهم يدور
- **touch.html**: نسخة اللمس والماوس.

فيها 13 شكل: كرة، قلب، حلقة، مجرة، نجمة، مكعب، DNA، إعصار، زحل، فراشة، وردة، موجة، نص.
