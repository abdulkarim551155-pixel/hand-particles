# جزيئات اليد ✋✨

جزيئات تتحرك بحركة يدك قدام الكاميرا، باستخدام MediaPipe Hands و Three.js.

- **index.html**: نسخة الكاميرا، تشتغل بيد وحدة أو يدين:
  - ✊ قبضة: تحرك الشكل
  - ✋ كف مفتوح: تلفّ الشكل
  - 👌 قرصة: الشكل التالي
  - ✌️ علامة النصر: الشكل السابق
  - 🙌 يدين: تبعدهم يكبر، تقربهم يصغر، تميّلهم يدور
- **touch.html**: نسخة اللمس والماوس.

فيها 23 شكل:
- **عادية:** كرة، قلب، حلقة، مجرة، نجمة، مكعب، DNA، إعصار، زحل، فراشة، وردة، موجة، نص
- **البعد الرابع (4D):** تسراكت، خماسي 4D، طارة كليفورد، ألياف هوبف، وكلها تلف في 4 أبعاد
- **مجنونة:** ثقب أسود، جاذب لورنز، زجاجة كلاين، شريط موبيوس، عقدة، جايرويد
